# AI Algorithm Visualizer — демо-видео

Готовое видео: `out/AI_Algorithm_Visualizer_demo.mp4`. Это MP4, H.264 High, yuv420p, 1920×1080, 60 fps, длительность 2:40. Звука нет, аудиодорожка отсутствует.

## Как сделано

Видео записано с **настоящего, неизменённого сайта** из архива (`app/` — копия `dist/`, контрольные суммы в `app.sha256`). Сайт открывается в headless Chromium через Playwright и записывается покадрово.

На каждом кадре (1/60 с):

1. По таймлайну вычисляются положение «камеры» и курсора.
2. Через Playwright отправляются **реальные** события мыши и клавиатуры: наведения, клики, перетаскивание ползунка скорости, ввод seed и стартового индекса.
3. Встроенные таймеры приложения (`setInterval` анимации A*/BFS/DFS) продвигаются ровно на 1/60 с. Поэтому скорость анимации в видео совпадает с выбранной в приложении: 20 мс на шаг для A* и BFS, 80 мс для DFS.
4. Делается снимок экрана, кадры передаются по конвейеру в ffmpeg.

Все числа в кадре вычислены самим приложением. Проба `out/facts.json` фиксирует то, что приложение реально показало во время рендера:

| Сцена | Результат приложения |
|---|---|
| Дайын лабиринт, A* | длина 24, зерттелген 99 |
| BFS | длина 24, зерттелген 189 |
| DFS | длина 38, зерттелген 39 («DFS ең қысқа жолға кепілдік бермейді») |
| Seed 2026, плотность 25 %, A* | длина 24, зерттелген 107 |
| Hill Climbing, старт 0 | 0 → 1 → 2, остановка на 7 (локальный максимум) |
| Hill Climbing, старт 5 | 5 → 6, значение 9 (глобальный максимум) |
| Random Restart (5 запусков, seed 42) | старты 2, 0, 5, 2, 3; лучший результат 9; глобальный максимум найден в 1 из 5 |
| Minimax, сложный режим | X5 O1 X3 O7 X4 O6 X8 O2 X9 → «Тең ойын!»; дерево последнего решения: O→2 (0, выбрано), O→9 (−8) |

Колонка «Есептеу уақыты» в таблице сравнения — это настоящее время, которое приложение измерило через `performance.now()` во время записи. В браузере оно округляется до 0,1 мс и меняется от запуска к запуску; так и подписано в самом приложении.

### Что добавлено поверх интерфейса

Всё это рисуется отдельным слоем и не меняет приложение:

- курсор, подсветка клика, рамки-выделения;
- подписи на казахском, титры, финальный список;
- «камера»: CSS-масштаб и сдвиг `<body>`, то есть плавное приближение к нужной части страницы;
- выпадающий список у `<select>`. Headless Chromium не отрисовывает нативное системное меню, поэтому список рисуется в стиле приложения. Он строится из настоящих `<option>`, а значение меняется через `selectOption`, то есть приложение получает настоящее событие `change`.

## Как пересобрать

Нужны Node.js 18+, Playwright с Chromium и ffmpeg.

```bash
npm install playwright        # если ещё не установлен
npx playwright install chromium
node src/render.cjs --out out/AI_Algorithm_Visualizer_demo.mp4
bash src/verify.sh out/AI_Algorithm_Visualizer_demo.mp4
```

Полезные режимы:

```bash
node src/render.cjs --fps 10 --stills 13,45,90,131 --dir out/stills   # отдельные кадры для проверки
node src/render.cjs --fps 10 --stills 1 --dir out/tmp --layout 1        # координаты элементов страницы
```

## Файлы

- `src/timeline.cjs` — сценарий: время каждого действия, подписи, кадры камеры, пробы результатов.
- `src/engine.cjs` — таймлайн, сглаживание движений, расчёт кадрирования.
- `src/render.cjs` — покадровая запись через Playwright и кодирование в ffmpeg.
- `src/overlay.js`, `src/overlay.css` — слой с курсором, подписями и выделениями.
- `src/verify.sh` — проверка готового MP4: потоки, отсутствие звука, fps, длительность, чёрные кадры, контрольные кадры.
- `app/` — исходный сайт без изменений.
- `out/facts.json` — значения, которые приложение показало во время рендера.
