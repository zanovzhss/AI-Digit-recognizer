# Measurements: reference set vs IceShort final

Private study. The first nine columns are the project's own `measure.py` (54x96 luma). The rest come from
`research/ricks/tools/` (`motion.py` at 216x384 sub-pixel, `transitions.py`, `analyze.py`): px values are px/frame at
1080 wide, zoom in %/frame (+ = push-in). Captions are burned into the reference, which adds a little to its medDiff.

Column key: movePct = % frames the camera is moving (pan >= 3 px/f or zoom >= 0.35 %/f); holdMedF / holdP90F = hold length in
frames (median / 90th pct); pushInPct = % frames creeping in (zoom > 0.04 %/f); holdPushMed = median push-in speed during
holds (%/f); fastPct = % frames with pan >= 40 px/f; wps = narration words/s; edge = detail density (share of strong-gradient
pixels in 135x240 stills, a proxy for set density); sat = mean HSV saturation.
